# JavaScript, TypeScript и Vue разбирает tree-sitter

Здесь решено, чем kartograph разбирает фронтенд и что считается ошибкой разбора.

## Контекст

kartograph нужны символы, импорты и места вызовов фронта: из них строятся рёбра `HTTP_CALLS` от компонента к
endpoint. Код фронта — JavaScript, TypeScript и однофайловые компоненты Vue. Правило полноты
([ADR-0001](0001-the-product-is-a-cli-over-a-current-graph.md)) требует, чтобы неразобранный файл приложения не
давал неполного графа.

## Решение

- **Парсер — tree-sitter через CGO** с грамматиками JavaScript, TypeScript и Vue.
- **tree-sitter даёт синтаксис, а не разрешение.** Разрешение импортов и целей вызовов делает kartograph.
- **Узлы `ERROR` и missing-узлы в файле приложения — ошибка разбора.** tree-sitter восстанавливается после ошибок
  и отдаёт дерево и для невалидного файла, поэтому kartograph проверяет дерево сам: такой файл даёт `index_failed`
  с причиной `parse_error` ([ADR-0003](0003-an-error-is-a-yaml-document-with-a-closed-code.md)), снимок не
  публикуется.
- **Ошибка разбора файла в `node_modules` подчиняется правилу зависимостей**
  ([ADR-0005](0005-dependencies-are-a-type-source.md)): неразрешённое место с причиной `dependency_unparsed`,
  снимок публикуется.

## Не решено

- Что из SFC Vue разбирается сверх блока `<script>`: выражения шаблона, `<script setup>`, язык блока по `lang` —
  [DEV-14016](https://yt.macrodigital.ru/issue/DEV-14016).
- Ключи приватных JS-сущностей и анонимных функций — [DEV-14016](https://yt.macrodigital.ru/issue/DEV-14016).

## Отвергнуто

- **Go-нативный парсер.** Парсер esbuild лежит во внутренних пакетах и библиотекой не подключается; парсер goja
  разбирает JavaScript без TypeScript и Vue. Свой парсер — сопровождение трёх грамматик.
- **Терпимость к узлам `ERROR`** (часть файла разобрана, остальное пропущено). Дерево после восстановления
  правдоподобно, но неполно: часть вызовов пропадает молча, а это и есть неполный граф.
- **Парсер на Node.js во внешнем процессе.** Пользователю пришлось бы ставить Node.js, а kartograph — запускать и
  кормить ещё один процесс.

## Следствия

- kartograph собирается с CGO; вместе с LadybugDB ([ADR-0007](0007-ladybugdb-is-linked-statically.md)) это бинарник
  на каждую платформу.
- Версии грамматик входят в ключ кеша фактов по файлу.
