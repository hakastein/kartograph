# Ошибка — YAML-документ с кодом из закрытого словаря

Здесь решено, как kartograph сообщает об ошибке, какие у неё коды и с каким кодом возврата он выходит.

## Контекст

Агент разбирает вывод программно и ветвится по нему. Граф либо актуален, либо его нет
([ADR-0001](0001-the-product-is-a-cli-over-a-current-graph.md)), поэтому сбой сборки — частый и содержательный
ответ: агенту нужно знать, что именно не дало построить граф и где это место. ytrack уже отдаёт агенту ответ одним
YAML-документом в stdout, а ошибку — YAML-документом в stderr с первым ключом `code`; kartograph следует той же форме,
чтобы агент разбирал оба инструмента одинаково.

## Решение

- **Ответ — один YAML-документ в stdout.** В каждом ответе — блок снимка: workspace, generation, HEAD, грязное ли
  дерево.
- **Ошибка — YAML-документ в stderr с первым ключом `code`.**
- **Коды возврата:** `0` — ответ; `1` — ошибка, документ в stderr; `2` — ошибка в аргументах вызова.
- **Словарь `code` закрыт:**

| Код | Что означает |
|---|---|
| `bad_usage` | вызов не разобран: аргументы или флаги |
| `not_a_workspace` | каталог вызова или названный путь — не workspace |
| `capture_unstable` | снимок не захвачен: дерево продолжало меняться после ограниченного числа повторов |
| `index_failed` | граф не построен полностью, новый снимок не опубликован; причина — в `cause` |
| `query_rejected` | запрос к графу не принят |
| `not_found` | названный объект не найден в графе |
| `internal` | дефект kartograph |

- **У `index_failed` есть поле `cause`** из закрытого словаря и место: файл с диапазоном или место в скрипте
  сборщика.

| `cause` | Что означает |
|---|---|
| `parse_error` | файл приложения не разобран ([ADR-0005](0005-dependencies-are-a-type-source.md), [ADR-0006](0006-js-and-vue-are-parsed-with-tree-sitter.md)) |
| `analyzer_crashed` | упал анализатор |
| `collector_failed` | сборщик бросил исключение или упал |
| `invalid_fact` | сборщик вернул невалидный факт |
| `missing_symbol` | факт ссылается на отсутствующий символ |
| `plan_cycle` | цикл в плане сборщиков ([ADR-0002](0002-a-collector-declares-itself-in-a-cliche-key.md)) |
| `collector_name_clash` | совпали имена сборщиков из разных источников |

- **Запрос, который не смог обновить устаревший снимок, отвечает ошибкой без результатов графового запроса.**

## Не решено

- Имена ключей места (файл и диапазон, место в скрипте), формат `message` и прочие поля документа ошибки.
- Какие ошибки, кроме `bad_usage`, считаются ошибкой в аргументах с кодом `2`.

## Отвергнуто

- **Ошибка текстом в stderr.** Агент не может надёжно ветвиться по прозе, а место сбоя пришлось бы выковыривать
  регуляркой.
- **Открытый словарь кодов, в том числе коды сборщиков.** Агент не знает заранее, по каким кодам ветвиться, а
  сборщик, придумавший свой код, ломает контракт для всех проектов. Дефект сборщика — `index_failed` с причиной
  `collector_failed` и местом в его скрипте.
- **Свой код возврата на каждый код ошибки.** Код возврата различает только ответ, ошибку и ошибку вызова; что
  случилось, говорит документ.
- **Ответ с предупреждением вместо ошибки при неполном графе.** Это и есть режим неполного графа, который отвергнут
  в [ADR-0001](0001-the-product-is-a-cli-over-a-current-graph.md).

## Следствия

- Новый код или причина появляются только правкой этого ADR.
- Неразрешённое место — данные графа, а не ошибка: оно в ответе, а не в stderr.
