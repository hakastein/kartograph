# kartograph

Слова, которыми о kartograph говорят решения, комментарии и тесты.

**Workspace**:
git worktree, по которому kartograph строит граф. Подмодули — часть его дерева; вложенные worktree и симлинки в
чужие деревья — нет.
_Avoid_: проект, репозиторий, checkout

**Снимок** (snapshot):
Неизменяемое состояние workspace, по которому строится граф: tracked-файлы, untracked-файлы вне ignore, сгенерированные
tracked-файлы, а также манифест зависимостей, конфиги и стабы, которые входят в его идентичность. Байты захватываются в
content-addressed хранилище, разбор идёт по захваченным байтам, а не по живому дереву.
_Avoid_: индекс, срез, версия

**Generation**:
Каталог хранилища с одним собранным снимком: файл графа LadybugDB, манифест и файлы аренды. Собирается один раз,
публикуется и больше не открывается на запись.
_Avoid_: база, сборка

**Указатель** (pointer):
Симлинк `workspaces/<id>/current`, который называет generation, текущую для workspace.
_Avoid_: ссылка, current-база

**Публикация** (publication):
Атомарная замена указателя на собранную и чисто закрытую generation.
_Avoid_: деплой, коммит

**Аренда** (lease):
Файл в каталоге generation, на котором читатель держит `flock`, пока читает. Пока аренда держится, generation не
убирается.
_Avoid_: блокировка (так называется блокировка хранилища), pin

**Блокировка хранилища** (store lock):
Блокировка, под которой читатель разыменовывает указатель и берёт аренду, а уборка решает, что удалить.

**Уборка** (gc):
Удаление generation, на которые не указывает ни один workspace и которые никто не арендует.
_Avoid_: очистка кеша

**Сборщик** (collector):
Скрипт на JavaScript, который kartograph исполняет через cliche, чтобы извлечь соглашения проекта: роутер,
HTTP-клиенты фронта, SQL-слой, точки входа. Универсальный (поставляется с kartograph), проектный (лежит в репозитории
проекта) или пользовательский (подключается явным указанием).
_Avoid_: плагин, экстрактор, правило

**Объявление сборщика** (collector declaration):
Значение ключа kartograph в `exports.definition` сборщика: входы, выходы и область действия. Читается без выполнения
скрипта.
_Avoid_: манифест, конфиг сборщика

**Область действия** (scope):
`file` — сборщик работает по одному файлу, и его результат кешируется по файлу; `snapshot` — по всему снимку.

**План** (plan):
Порядок запуска сборщиков: DAG по их объявленным входам и выходам. Цикл — ошибка объявления.

**Факт** (fact):
Узел или ребро с обоснованием, которое дал анализатор, разбор JS/Vue или сборщик. Факты прохода сборщика
принадлежат этому проходу и заменяются целиком.
_Avoid_: запись, результат

**Обоснование** (provenance):
Кто установил ребро (анализатор или сборщик и его версия), по какому правилу и в каком месте кода (файл и диапазон).
_Avoid_: confidence, вес

**Неразрешённое место** (unresolved site):
Место в коде, цель которого статически не установлена, с причиной: динамический URL, динамический SQL, динамический
диспатч, неразобранный файл зависимости (`dependency_unparsed`). Это данные графа, а не сбой: путь через него
выдаётся как «не установлено», а не как «нет».
_Avoid_: неизвестная связь, пропуск, warning

**Ошибка разбора** (parse error):
Файл приложения, который парсер не разобрал. Снимок с ней не публикуется (`index_failed`, причина `parse_error`).
_Avoid_: неразрешённое место (это другое)

**Цель по объявлению** (declared target):
Цель вызова по объявленному типу. Отличается от **возможных реализаций** — переопределений и реализаций интерфейса,
которые являются статическими кандидатами, а не доказанными целями рантайма.

**Роль обхода** (traversal role):
Объявленное проектом свойство ребра его вида: как ребро участвует в `trace` и `impact`. Ребро вида без роли в
стандартный обход не входит.
_Avoid_: вес ребра, направление

**Точка входа** (entry point):
Место, откуда начинается выполнение помимо HTTP: консольная команда, cron-задача, обработчик очереди. Объявляется
сборщиками проекта.

**Endpoint**:
HTTP-точка сервиса: сервис или хост, HTTP-метод и нормализованный путь. Нормализацию задаёт проектный сборщик.
Endpoint'ы разных сервисов с одинаковым путём — разные узлы.
_Avoid_: роут, URL, ручка

**Логический ключ** (logical key):
Ключ, по которому сопоставляются узлы разных снимков: PHP — язык, вид и полное имя; JS/Vue — путь модуля, экспорт и
член; endpoint — сервис или хост, метод и нормализованный путь; SQL — логическое подключение, схема, таблица,
колонка. Переименование даёт новый логический ключ.
_Avoid_: id, ключ символа (он уникален только внутри снимка)
